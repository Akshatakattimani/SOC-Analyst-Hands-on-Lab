# SOC Analyst Hands-on Lab

## 📌 Project Overview

This project demonstrates the design and implementation of a hands-on Security Operations Center (SOC) lab using Splunk Enterprise, Wazuh, Elastic Security, Kali Linux, Windows, and Oracle VirtualBox. The lab simulates real-world security monitoring, log analysis, threat hunting, incident detection, and alerting activities performed by a Security Operations Center (SOC) Analyst.

---

## 🎯 Objectives

- Build a practical Security Operations Center (SOC) lab.
- Monitor Windows and Linux security events.
- Perform log analysis and threat hunting.
- Investigate security incidents using SIEM tools.
- Configure dashboards and alerts.
- Gain hands-on experience with enterprise security technologies.

---

## 🏗️ Lab Architecture

### Lab Components

- **Host Machine:** Windows 11
- **Virtualization Platform:** Oracle VirtualBox
- **Attacker Machine:** Kali Linux
- **Target Machine:** Windows
- **SIEM Platform:** Splunk Enterprise
- **Endpoint Detection & Response:** Wazuh
- **Security Analytics:** Elastic Security
- **Visualization:** Kibana
