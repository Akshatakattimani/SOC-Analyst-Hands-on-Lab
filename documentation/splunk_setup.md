# Splunk Enterprise Setup

## Overview

Splunk Enterprise was deployed as the primary Security Information and Event Management (SIEM) platform in the SOC lab.

---

## Purpose

The Splunk instance was configured to:

- Collect security logs
- Index events
- Search and analyze logs
- Create dashboards
- Generate alerts
- Support threat hunting activities

---

## Configuration Summary

| Component | Configuration |
|-----------|---------------|
| Platform | Splunk Enterprise |
| Operating System | Windows 11 |
| Data Sources | Windows Event Logs, SSH Logs |
| Search Language | SPL |
| Dashboards | Custom Security Dashboards |
| Alerts | Scheduled Alerts |

---

## Practical Activities

During this project, I performed:

- Log ingestion
- SPL query development
- Dashboard creation
- Scheduled report creation
- Alert configuration
- Login event monitoring
- SSH log analysis
- Security event investigation

---

## Outcome

Splunk Enterprise served as the central SIEM platform for monitoring and investigating security events throughout the SOC lab.
