# Elastic Security Setup

## Overview

Elastic Security was integrated into the SOC lab to provide centralized security analytics, endpoint monitoring, threat detection, and interactive dashboards.

---

## Purpose

Elastic Security was configured to:

- Collect endpoint security events
- Monitor system activity
- Create security dashboards
- Detect suspicious behavior
- Support threat hunting
- Visualize security data using Kibana

---

## Configuration Summary

| Component | Configuration |
|-----------|---------------|
| Platform | Elastic Security |
| Dashboard | Kibana |
| Agent | Elastic Agent |
| Data Source | Windows Endpoint |
| Integration | Fleet |
| Visualization | Kibana Dashboards |

---

## Practical Activities

During this project, I performed:

- Elastic Agent installation
- Fleet configuration
- Endpoint monitoring
- Dashboard creation
- Threat hunting
- Event investigation
- Security visualization

---

## Outcome

Elastic Security provided centralized visibility into endpoint events, enabling efficient monitoring, investigation, and visualization of security data within the SOC lab.
