# SOC Analyst Hands-on Lab Setup

## Overview

This document describes the setup of my Security Operations Center (SOC) lab environment used for security monitoring, log analysis, threat hunting, and incident investigation.

---

## Lab Environment

| Component | Details |
|-----------|---------|
| Host Operating System | Windows 11 |
| Virtualization Platform | Oracle VirtualBox |
| Attacker Machine | Kali Linux |
| Target Machine | Windows |
| SIEM Platform | Splunk Enterprise |
| Endpoint Detection & Response | Wazuh |
| Security Analytics | Elastic Security |
| Dashboard | Kibana |

---

## Objectives

- Build a practical SOC lab.
- Collect and analyze security logs.
- Perform threat hunting.
- Configure alerts and dashboards.
- Investigate security incidents.
