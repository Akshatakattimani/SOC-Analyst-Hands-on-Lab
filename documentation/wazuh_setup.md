# Wazuh Setup

## Overview

Wazuh was deployed in the SOC lab to provide endpoint detection, security monitoring, log collection, and active response capabilities.

---

## Purpose

Wazuh was configured to:

- Monitor endpoint security events
- Detect suspicious activities
- Collect Windows security logs
- Generate security alerts
- Support threat hunting
- Configure Active Response

---

## Configuration Summary

| Component | Configuration |
|-----------|---------------|
| Platform | Wazuh |
| Deployment | Virtual Lab |
| Agent | Windows Endpoint |
| Dashboard | Wazuh Dashboard |
| Detection | Custom Rules |
| Active Response | Enabled |

## Practical Activities

During this project, I performed:

- Agent deployment

## Outcome

Wazuh enhanced endpoint visibility by collecting security events, generating alerts, and supporting threat detection and response within the SOC lab.
